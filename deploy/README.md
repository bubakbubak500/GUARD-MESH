# Support files retained by GUARD-MESH

- `apps/`: Lua applications, catalogs and translations used by the firmware build.
- `files/`: USB file manager, retained for later desktop tooling.
- `flasher/`: local offline installer; see [instructions](../docs/LOCAL-FLASHER.md).

The public website, VPS configuration, external publication catalogs and publish
scripts have been removed. Text-only upstream documentation is in [docs](../docs/README.md).
Firmware web control and upstream service URLs are unchanged in this phase.
